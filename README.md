# Leader Packs

Historical generals, field marshals and admirals that Hearts of Iron IV leaves out, one pack per country, with portraits painted from period photographs.

## Overview

- **Game**: Hearts of Iron IV
- **Supported Version**: `1.19.*`
- **Tags**: Historical, Military, Gameplay
- **Packs**: Finland, France and Poland, each published as its own Steam Workshop item "Commanders Pack: <Country>"
- **Bundle**: "Immersive Commanders Expanded" holds every pack in one Workshop item. The Workshop page asks players to pick the bundle or single packs.
- **New games only**: a pack recruits its leaders at game start, so it needs a new game.
- **Portraits**: each portrait is a repaint of a period photograph. The photos are public domain or CC0 today; the licence policy also admits CC BY and CC BY-SA. The photo credits are on each pack's page in the GitHub wiki.

One source repository holds all of it. Everything a pack ships, except its `descriptor.mod` and `thumbnail.png`, is generated by `build.ps1` from the hand-written files in `source/<pack>/` and the game-data snapshots in `data/`. The file formats and the switches are in `docs/source-format.md`; the rules for choosing stats and traits are in `docs/stat-guide.md`.

```
|-- assets/                         # Thumbnail master art and thumbnail settings
|-- docs/                           # source-format.md, stat-guide.md and plans/ (plans in progress, archive/ for shipped ones)
|-- tests/                          # Automated Pester test suites
|-- tools/                          # LeaderPacks.ps1, convert_portraits.py, review page tools and the shared build engine
|-- wiki/                           # GitHub wiki pages: the generated page per pack, the hand-written Home.md, Contributing.md and _Sidebar.md, and the script that pushes them
|-- .claude/                        # Agent skills, agents, hooks and settings for the work on this repository
|-- .agents/                        # Only the skills mirror (a copy of .claude/skills)
|-- .github/                        # CI workflow
|-- .gitattributes                  # Line-ending rules
|-- *.mod                           # Launcher files in the repository root (git-ignored)
|-- scratch/                        # Working files of a session (git-ignored)
|-- sources-cache/                  # Downloaded originals of the leader photos (git-ignored)
|-- artifacts/                      # Packaged archives and Workshop gallery images (git-ignored)

```

## Development & Automation Commands

All lifecycle tasks are managed through `build.ps1`. Every pack action takes `-Pack <pack>` (`finland`, `france`, `poland`); `-Pack all` names the bundle, which the lifecycle switches leave out otherwise.

```powershell
# 1. Generate a pack's mod files from source/<pack>/ and data/
.\build.ps1 -Generate -Pack poland

# 2. Convert the chosen portraits to the game's formats
.\build.ps1 -ConvertPortraits -Pack poland

# 3. Check the pack against the rules of docs/source-format.md (the bundle: -Check -Pack all)
.\build.ps1 -Check -Pack poland

# 4. Deploy the pack to the local Paradox Interactive Hearts of Iron IV mod folder
.\build.ps1 -Deploy -Pack poland

# 5. Configure zero-copy DevLink (the launcher loads the folder itself; restart the game to see a change)
.\build.ps1 -DevLink -Pack poland
#    The bundle: .\build.ps1 -DevLink -Pack all links a git-ignored .devlink folder of hard links to every pack's files;
#    .\build.ps1 -DevLink -CheckLinks -Pack all reports links that a checkout or pull broke

# 6. Validate syntax and bracket balance without deploying
.\build.ps1 -ValidateOnly

# 7. Run automated test suites (Pester)
.\build.ps1 -Test

# 8. Package a release zip archive
.\build.ps1 -Package -Pack poland

# 9. Clean deployed mod files and temporary archives
.\build.ps1 -Clean -Pack poland
```

`Get-Help .\build.ps1` prints only the parameter syntax. The pack switches (`-NewPack`, `-FindPhoto`, `-FetchPhoto`, `-MakePortraits`, `-ReviewPage`, `-ApplyPortraitReview`, `-RefreshGameData`, `-Audit`, `-RenderShowcase`, ...) are described in `docs/source-format.md` and, for agents, in `AGENTS.md`. Making portraits needs the Modding Manager's local ComfyUI recipe; `-RefreshGameData` and `-RenderShowcase` need the game install; `-ConvertPortraits`, `-PreviewPortraits` and `-ReviewPage` need Python 3 with Pillow.

## Release

A pack is not published with `build.ps1 -PublishSteam`. The release goes through the Hearts of Iron IV Modding Manager, which holds this repository under `mods/leader-packs` and keeps the Workshop upload script, the preflight checks and the Workshop text tools:

```powershell
# Preflight, then a dry run that prints the upload files, then the upload (from the Modding Manager's folder)
.\Scripts\Publish-Mod.ps1 "Leader Packs" -Pack poland -PreflightOnly
.\Scripts\Publish-Mod.ps1 "Leader Packs" -Pack poland -DryRun -ChangeNote "<note>"
.\Scripts\Publish-Mod.ps1 "Leader Packs" -Pack poland -ChangeNote "<note>"
```

A pack upload also uploads the bundle in the same run (`-SkipBundle` leaves it out). `-UpdateDescription` replaces the Workshop description with the generated `packs/<pack>/WORKSHOP_DESCRIPTION_GUIDELINES.md`. The thumbnail is drawn by the Manager's `Scripts/Showcase/New-HoiThumbnail.ps1`, and the wiki is pushed with `.\wiki\push-wiki.ps1`.

## Automated Testing

Unit tests are written with [Pester](https://pester.dev) and located in `tests/`. Execute tests using:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\Run-Tests.ps1
```
